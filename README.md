# Handle Missing Values Project

**Student:** Pranjal Jain

Files:
- `Handle_Missing_Values_Practice.ipynb` — exploration and cleaning notebook
- `titanic_missing_values.csv` — original dataset with missing values
- `Project_Report_Pranjal_Jain.pdf` — project report
- `requirements.txt` — dependencies

Methods: `isnull().sum()`, missing-value percentages, median imputation for numerical columns, mode imputation for categorical data, `dropna()` demonstration, and export of cleaned data.

Run `pip install -r requirements.txt`, then open the notebook in Jupyter Notebook or VS Code.
